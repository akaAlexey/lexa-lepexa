# ADR 0005. Платформенные интерфейсы

- Статус: принято
- Контекст: Android в этой фазе не собираем, но и не блокируем. Геопозиция, уведомления, хранилище, камера различаются между вебом и нативом, а на показе не должны зависеть от GPS и разрешений.

## Решение

Экраны зависят только от интерфейсов `src/platform/types.ts`, реализации внедряются через контекст (`ServicesProvider`).

| Интерфейс        | Веб (сейчас)                               | Демо                                                     | Android (потом)                                        |
| ---------------- | ------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------ |
| `GeoService`     | Geolocation API                            | `createDemoGeo` — точка из конфига региона, по умолчанию | `@capacitor/geolocation`                               |
| `NotifyService`  | Web Notifications                          | тост в приложении всегда                                 | `@capacitor/local-notifications`, push (FCM / RuStore) |
| `StorageService` | localStorage с запасным хранением в памяти | —                                                        | `@capacitor/preferences`                               |

По умолчанию геопозиция демо: показ не зависит от GPS. Реальный GPS включается ключом `geo-mode = device` (переключатель появится в демо-пульте). Камеру («тогда и сейчас», «Живое фото») добавим тем же способом, когда до неё дойдёт очередь — пустых интерфейсов заранее не держим.
