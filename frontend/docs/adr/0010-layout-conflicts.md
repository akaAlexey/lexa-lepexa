# ADR 0010. Конфликты референса с кейсом и нашими правилами

- Статус: принято арбитром (2026-09-24)

## 1. Домашний экран у всех — карта, а главный сценарий роли — не больше 3 нажатий

**Решение:** карта — домашний экран у всех. **Карточка внизу зависит от роли**, её главная кнопка — главный сценарий роли.

| Роль                     | Карточка                                      | Главная кнопка                                                  | Нажатий |
| ------------------------ | --------------------------------------------- | --------------------------------------------------------------- | ------- |
| Без роли (первый запуск) | Лист «Кто вы?»                                | Выбор роли — первое нажатие, как сейчас                         | 1       |
| Семья                    | «Семейный маршрут 01 / 04»                    | «Открыть первую точку» / «Продолжить тропу»                     | 1       |
| Командир                 | «Отряд „Высота“», слой «Места поиска» включён | «Отметить место гибели» → «Опубликовать»                        | US3: 2  |
| Командир                 | та же карточка, вторичная кнопка              | «Набрать волонтёров» → «10» → «Опубликовать»                    | US2: 3  |
| Волонтёр                 | Ближайшая открытая заявка                     | «Стать частью команды»; вторичная — «Сообщать о находках рядом» | 1       |
| Краевед                  | «Ждут проверки: N»                            | «Проверить следующую»                                           | 1       |

Нажатия считаются от домашнего экрана роли (ACCEPTANCE.md). Ввод текста нажатием не считается. E2e каждой user story считает нажатия явно.

## 2. Функции референса вне кейса

| Функция референса                       | Решение                                                                                                                     | Почему                                                                                            |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Регистрация по телефону с SMS-кодом     | Не делаем                                                                                                                   | Противоречит «выбору роли без регистрации», нужны сервер и обработка персональных данных (152-ФЗ) |
| Статусы от администратора               | Не делаем. Витрина: у роли командира строка «В настоящей версии статус подтверждает администратор»                          | Нужен сервер и процесс модерации                                                                  |
| Чат с администратором и фото            | Не делаем (A5 — P2)                                                                                                         | Нет сервера файлов и модерации                                                                    |
| «Проверка объявления» перед публикацией | **Витрина без лишнего шага:** в форме над «Опубликовать» список «Проверено: дата, место, контакт» из тех же правил `domain` | Отдельный шаг ломает «заявку командира за 3 нажатия»                                              |
| «Мой аккаунт»                           | **Витрина:** «Профиль» — демо-роль и «Мой контакт» только на устройстве. Контакт подставляется в личную и групповую заявку  | Без сервера и без сбора данных                                                                    |

## 3. «Места поиска» на референсе пустые

Это наш «Последний бой». Содержимое переносим полностью: три статуса с иконкой и подписью, захоронения фоном, легенда, список мест, карточка места, закрытые координаты, подписка на 20 км, «Я готов помочь в подъёме», форма находки. «Отметить место гибели» — главное действие командира.

## 4. Данные жюри

Файлы жюри (`mock_graves.csv`, `mock_battles.json`, `mock_teams.json`) организаторы не предоставили. Работаем на демо-данных, сгенерированных по схеме, с пометкой «Демо-данные». Когда файлы появятся, их нужно положить в `fixtures/jury/` и запустить `npm run fixtures`.
