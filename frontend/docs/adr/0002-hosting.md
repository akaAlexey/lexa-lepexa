# ADR 0002. Хостинг демо и HTTPS

- Статус: принято; хостинг пока не подключён
- Контекст: репозиторий приватный, сайт должен открываться из России без VPN, по HTTPS (геопозиция, service worker и уведомления работают только в защищённом контексте) и по QR-коду.

## Решение
1. **Сейчас — временный туннель.** `npm run tunnel` собирает приложение, поднимает `vite preview` и пробрасывает его через localhost.run по ssh (ничего не устанавливается). Даёт `https://<случайное>.lhr.life`, пока процесс запущен. Только для проверки на телефоне и показа каркаса.
2. **Цель — VPS в РФ + Caddy** (`deploy/Caddyfile`, `npm run deploy` с `DEPLOY_TARGET=user@host:/путь`). Caddy сам выпускает сертификат Let's Encrypt, отдаёт `index.html` для прямых ссылок и проксирует `/api` на бэкенд на том же домене — нет mixed content и не нужен CORS. Стоимость около 300–500 ₽/мес, оплата картой РФ.
3. **Запасной вариант** — статический сайт в Yandex Object Storage с сертификатом.

## Отклонено
- GitHub Pages — для приватного репозитория нужен платный тариф.
- Vercel, Netlify, Cloudflare Pages — нестабильная доступность из РФ.

## Последствия
- Ссылка туннеля меняется при каждом запуске; постоянный QR-код появится вместе с доменом.
- Пока хостинга нет, приёмка идёт по локальному `npm run verify` и скриншотам Playwright.
