# ADR 0006. Тесты и команда verify

- Статус: принято
- Контекст: «готово» — только когда тесты зелёные. Арбитр принимает по поведению, тестам и скриншотам.

## Решение
| Уровень | Инструмент | Что проверяет |
|---|---|---|
| Unit | Vitest (среда node) | доменная логика: расстояния, радиус 20 км, переходы статусов, прогресс сборов, контракт и фикстуры, маршрут ≈3 км |
| Компонентные | Vitest + Testing Library (jsdom) | экраны целиком через `renderApp()`; карта подменена заглушкой (в jsdom нет WebGL) |
| E2E | Playwright, проекты `phone` (360×780) и `laptop` (1366×768) | пользовательские сценарии, прямые ссылки, «Назад», axe (WCAG 2.1 AA), отсутствие ошибок в консоли; скриншоты в `e2e/screenshots/<вьюпорт>/` |

- E2E идут на production-сборке в режиме `e2e`: mock-API без задержек, без внешних тайлов — не зависят от сети.
- `npm run verify` = typecheck → lint (oxlint с jsx-a11y) → prettier --check → unit + компонентные → e2e.
- Линтер: oxlint вместо ESLint — один бинарник, встроенные правила react, jsx-a11y, import, vitest, быстрый.
