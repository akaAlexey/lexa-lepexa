# ADR 0007. Состояние: TanStack Query + React context

- Статус: принято (упрощение по итогам ревью: Zustand убран)

## Решение

- **Серверное состояние** — TanStack Query: кэш, повтор, состояния загрузки и ошибки (`QueryState`). В P0 кэш в памяти: фикстуры встроены в бандл, после загрузки данные доступны без сети. Сохранение кэша в IndexedDB — P1 вместе с офлайн-режимом.
- **Клиентское состояние** (роль, демо-геопозиция, прогресс квеста) — React context + `StorageService`. Для трёх значений отдельная библиотека не нужна.
