# ADR 0003. Карта: MapLibre GL JS, стиль из токенов, сменный источник тайлов

- Статус: принято; карту и дизайн команда будет дорабатывать
- Контекст: без API-ключей и зарубежной оплаты, стиль «военная картография», атрибуция OSM, работа без сети после загрузки, перенос на Android без переписывания.

## Решение
- **Движок** — MapLibre GL JS 6 (BSD, без ключей). Загружается лениво, отдельным чанком, только на экранах с картой.
- **Стиль** собирается в коде (`src/map/style.ts`) из токенов темы (`src/theme/tokens.ts`, раздел `color.map`). Дизайнер меняет цвета в одном месте — меняются и интерфейс, и карта. Стиль не грузится по сети, поэтому без сети остаются бумажный фон и наши слои. Тот же JSON понимает MapLibre Native.
- **Источник тайлов** — одна настройка `VITE_TILES` (`src/map/tiles.ts`):
  - `openfreemap` — векторные тайлы OSM без ключа (схема OpenMapTiles), атрибуция «OpenFreeMap © OpenMapTiles, данные © участники OpenStreetMap»;
  - `none` — только бумажный фон и наши слои (e2e, отказ сети);
  - P1: `pmtiles` — вырезка района Орла на своём хостинге (та же схема, тот же стиль, офлайн-кэш района выезда).
- **Метки — настоящие кнопки** (DOM-маркеры через React-портал): фокус с клавиатуры, подписи для скринридера, `testID`. Каждый экран с картой дублирует метки списком.
- **«След танка»** — две пунктирные колеи по бокам линии маршрута.
- **Воркер MapLibre** собирается Vite явно (`?worker&url` + `setWorkerUrl`): пакет ищет файл воркера рядом со своим чанком, а Vite его туда не кладёт.

## Контраст
Все пары текст/фон в токенах — не ниже WCAG AA: основной текст 12,3:1, вторичный 6,6:1, белый на красной кнопке 6,5:1, цвета статусов на карточке 6,0–7,8:1.

## Отклонено
- Растровые тайлы tile.openstreetmap.org — правила OSM запрещают активное использование и массовое скачивание, стиль не перекрасить.
- Leaflet — нет векторного стиля, общего с Android.
- Google Maps, Mapbox, 2ГИС — ключи и оплата.
