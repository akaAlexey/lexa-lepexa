# ADR 0009. Релизная раскладка по референсу «Полевой атлас»

- Статус: принято (итерация «релизная раскладка», 2026-09-24)
- Контекст: команда утвердила референс `frontend/docs/design/reference.html`: четыре раздела, карта-хаб со слоями, аккаунт в шапке. Наши правила (доступность, одна главная кнопка, 3 нажатия, этика) сильнее референса.

## Решение

**Разделы:** «Карта», «Помочь», «Выезды», «Истории».

- На телефоне — нижнее меню из четырёх пунктов.
- На ноутбуке — светлая панель слева. Её ширина задаётся одной CSS-переменной, от неё считается и положение карты.
- Аккаунт — кнопка в шапке справа: «Войти» или роль. Она ведёт на `/profile`.

**Шапка:** знак, «ТРОПА ПАМЯТИ · ОРЛОВСКАЯ ОБЛАСТЬ», заголовок экрана антиквой (PT Serif), подзаголовок.

**Карта** — домашний экран.

- Поверх карты: поиск «Найти место или человека», чипы-слои «Маршруты / Места поиска / Истории», годы у слоя «Истории», «Где я?», «Проложить путь».
- Внизу карточка роли или выбранного объекта.
- Порядок в DOM: поиск → чипы → карточка → карта. Список меток остаётся альтернативой карте.
- Чипы меняют адрес с `replace`: «Назад» не перебирает слои.
- Карточка поднимается на высоту тоста (`--toast-space`), чтобы тост не закрывал главную кнопку.

**Куда переезжают экраны**

| Было            | Стало                                                                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| «Тропа»         | Слой «Маршруты» и карточка маршрута. Точка — «История места» (кратко, источник, задание для ребёнка) и «Подробнее о событии»                                                   |
| «Последний бой» | Слой «Места поиска» — всё содержимое без потерь: три статуса, захоронения фоном, легенда, список, карточка места, закрытые координаты, подписка, «готов помочь», форма находки |
| «Хроника»       | Слой «Истории» с годами. Лента по годам — `/stories/chronicle`                                                                                                                 |
| «Поисковикам»   | «Помочь»                                                                                                                                                                       |
| «Выходные»      | «Выезды»                                                                                                                                                                       |
| «Истории»       | «Истории»                                                                                                                                                                      |
| Выбор роли      | При первом запуске — лист «Кто вы?» на карте, потом «Профиль» за кнопкой аккаунта                                                                                              |
| `/demo`         | Без изменений, без пункта меню                                                                                                                                                 |

**Адреса.**

- Новые: `/map?layer=routes|places|stories&year=`, `/routes/:r/points/:p`, `/routes/:r/finish`, `/places/new`, `/places/:id`, `/help`, `/help/requests/new`, `/trips`, `/trips/:id`, `/trips/:id/group`, `/stories`, `/stories/new`, `/stories/:id`, `/stories/chronicle`, `/profile`, `/demo`.
- `/` ведёт на `/map`.
- Старые адреса (`/trail…`, `/last-battle…`, `/search…`, `/weekends…`, `/archive…`, `/chronicle`) навсегда остаются редиректами: они есть в QR-кодах и ссылках «Поделиться».
- Редирект — компонент с `replace`: сохраняет query и hash, не оставляет ловушки для «Назад».
- Id сущностей не могут быть `new`, `mine`, `chronicle`. Это правило контракта.

**Визуальный язык — токены** (`src/theme/tokens.ts`).

| Что               | Значение                                                                      |
| ----------------- | ----------------------------------------------------------------------------- |
| Фон               | `#E1E4D0`                                                                     |
| Карточка          | `#F5F2E6`                                                                     |
| Тушь              | `#2E3829`                                                                     |
| Основной цвет     | `#52663E`                                                                     |
| Шапка             | `#2D3E2C` → `#354833`                                                         |
| Панель разделов   | `#E5EADB`                                                                     |
| Латунь `#B69A60`  | Только декор (кромка главной кнопки)                                          |

Главная кнопка оливковая с латунной кромкой. Красный остаётся статусу «Обнаружено место». Если команда скажет «оставить палитру Универсального варианта», меняется только раскладка.

## Отступления от референса ради наших правил

| Референс                                                              | Мы                                    | Правило                           |
| --------------------------------------------------------------------- | ------------------------------------- | --------------------------------- |
| Бледные плашки-«герои», текст ~2:1                                    | Текст на плашках ≥ 4,5:1              | WCAG AA                           |
| Латунный текст `#AC7B42` (3,3:1)                                      | Затемнён до ≥ 4,5:1                   | WCAG AA                           |
| Неактивный пункт меню `#66715B` на `#E5EADB` (4,2:1)                  | Затемнён до ≥ 4,5:1                   | WCAG AA                           |
| Кнопки и чипы 39–46 px                                                | Не меньше 48 px                       | Зоны нажатия                      |
| Подписи меню 11 px, чипов 12 px                                       | Не меньше 16 px                       | Крупный шрифт для детей и пожилых |
| Метки только цветом                                                   | Иконка или номер и подпись            | Статус не только цветом           |
| Несколько «главных» кнопок на экране                                  | Одна `BigButton`, остальные вторичные | Одна главная кнопка               |
| Эмодзи в кнопках                                                      | Свои SVG-иконки                       | Единый стиль, скринридер          |
| Рамка телефона, левая панель-описание, переключатель «Смартфон / Веб» | Не переносим                          | Это оформление макета             |

Контраст каждой пары «текст / фон» из токенов проверяет unit-тест (≥ 4,5:1, декор ≥ 3:1).
