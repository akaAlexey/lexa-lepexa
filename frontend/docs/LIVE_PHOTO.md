# «Живое фото» — снимок с QR-кодом, который говорит

Модуль из кейса («Живое фото / AI-оживление»). На табличке у памятника или на стенде висит снимок бойцов с QR-кодом в углу. Посетитель сканирует код камерой телефона, открывается страница приложения `…/live/<id>`, он соглашается с этической оговоркой и наводит камеру на снимок. Приложение узнаёт снимок и накладывает на него ролик, где бойцы оживают и произносят записанную заранее речь.

## Что сейчас есть

| Снимок            | Адрес QR                                               | Ролик                                                                                                                  |
| ----------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Офицер (портрет)  | https://akaalexey.github.io/lexa-lepexa/live/soldier   | Говорящее лицо (Hedra): губы совпадают с речью, голос — ElevenLabs v3, 22,6 с                                          |
| Бойцы у Рейхстага | https://akaalexey.github.io/lexa-lepexa/live/reichstag | Kling 3.0: 10 с бойцы переговариваются (три голоса ElevenLabs v3), затем 5 с — вскидывают руки под «Ура» хором, 16,5 с |

Файлы в `public/live/`: снимок с QR (`*.jpg`, он же печатается), ролик (`*.mp4`), субтитры (`*.vtt`), метка для распознавания (`*.mind`).

## Как работает в браузере

- `features/live-photo`: список `/live` и страница снимка `/live/:photoId`. Сначала показываются текст речи, этическая оговорка и галочка согласия. Затем главная кнопка «Навести камеру на снимок»; есть запасной вариант «Смотреть без камеры».
- Распознавание — `platform.ar` (`platform/web/ar.ts`): MindAR узнаёт снимок по метке `.mind`, three.js кладёт ролик текстурой ровно на рамку снимка. Библиотеки подгружаются с jsDelivr только при открытии камеры. Карта импорта для `three` лежит в `index.html`.
- Этика по кейсу: согласие до просмотра; пометка «Реконструкция с помощью ИИ» постоянно на экране камеры, на плеере и в самом ролике; текст от первого лица виден заранее; субтитры для глухих и слабослышащих.

## Как пересобрать ролики

Всё тяжёлое считается в облаке, видеокарта компьютера не нужна. Готовые ролики сделаны через агрегатор ERA2.ai:

| Этап            | Сервис                                  | Что на входе                                                                                     | Цена     |
| --------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------ | -------- |
| Голоса          | ElevenLabs v3, Text-to-Dialogue         | Реплики с тегами эмоций: офицер — Vlasov; бойцы — Valery, Evelon_rus, Zion; «Ура» — пять голосов | ≈95 кр.  |
| Офицер          | Hedra                                   | Снимок с QR + дорожка голоса                                                                     | —        |
| Бойцы, разговор | Kling 3.0, 10 с, 720p, «по двум кадрам» | Первый и последний кадр — первый кадр клипа «Ура», поэтому стык не виден                         | 1150 кр. |
| Бойцы, «Ура»    | Kling 3.0, 5 с, 720p                    | Снимок, дополненный полями до 16:9                                                               | 575 кр.  |

Промпт разговора: статичная камера без наезда; бойцы по очереди говорят, остальные поворачиваются к говорящему, кивают; в конце все возвращаются в исходную позу.

Склейка — `scripts/live-photo/assemble.sh` (ffmpeg): нарезка реплик, хор «Ура» из пяти голосов со сдвигом, «патина радиосвязи», заплатка из исходного снимка на месте QR (в роликах нейросети QR выходит размытым), пометка «Реконструкция с помощью ИИ». Кадр Hedra 2:3 ложится на снимок 500×716 со сдвигом 11 px — края берутся из неподвижного снимка, и в камере ролик совпадает с отпечатком.

```bash
bash scripts/live-photo/assemble.sh <папка-этапов> <снимки-без-QR> arialbd.ttf
python scripts/live-photo/stamp_qr.py work/solo.png soldier public/live/soldier.jpg 150
node scripts/live-photo/compile_targets.mjs public/live soldier reichstag
```

Бесплатный запасной путь — Hugging Face Spaces (`make_audio.py`, `cloud_video.py`: Edge TTS, LTX-Video, MoDA). Без входа ZeroGPU даёт около 3 минут в сутки; с токеном — переменная `HF_TOKEN` в своей консоли, в репо не попадает.

## Надёжность камеры

- Камера включается только после согласия и только на https: на `http://` сразу понятная ошибка и ролик без камеры.
- Запуск ограничен 20 секундами: если MindAR не стартовал (например, не загрузилась цель `.mind` — тогда MindAR падает внутри себя и сам не завершается), запуск отменяется, камера гаснет, предлагаются «Включить камеру снова» и «Смотреть без камеры».
- Камера гаснет при закрытии, ошибке, таймауте, уходе с экрана, свёртывании браузера (`visibilitychange`) и `pagehide`. `platform/web/ar.ts` сам гасит дорожки камеры, даже если `mindar.stop()` не сработал; события «найден/потерян» после остановки игнорируются.
- В режиме камеры текущая реплика субтитров выводится внизу экрана; дорожка `.vtt` в это время скрыта и потом возвращается плееру.
- Ролики подготовлены заранее: интерфейс нигде не называет их созданными в момент показа.

- Компонентные: `LivePhoto.test.tsx`, `LivePhotoReliability.test.tsx` (согласие, fallback, таймаут, свёртывание, уборка обработчиков, субтитры в камере, пометка ИИ, базовый путь Pages).
- e2e: `e2e/live-photo.spec.ts` (экраны, согласие, ролик и субтитры отдаются сервером).
- Настоящее распознавание: `e2e/live-photo-ar.spec.ts` — вместо камеры Chromium получает видеопоток со снимком; проверяет и то, что камера гаснет после закрытия, сбоя цели и свёртывания. Нужна сеть (jsDelivr), поэтому запускается вручную:

  ```bash
  python scripts/live-photo/fake_camera.py public/live/soldier.jpg soldier.y4m
  LIVE_AR_CAMERA=soldier.y4m LIVE_AR_PHOTO=soldier npx playwright test e2e/live-photo-ar.spec.ts
  ```

- На телефоне: [LIVE_PHOTO_MOBILE_CHECKLIST.md](LIVE_PHOTO_MOBILE_CHECKLIST.md).

## Ограничения

- Снимки взяты из открытых архивных публикаций для демо. Чтобы разместить их у памятника, нужно согласие родственников и атрибуция снимка.
- На групповом снимке губы точно под слова не подогнаны: нейросети подгонки губ работают с одним лицом. Kling двигает губы говорящих бойцов, на общем плане и с «радио» это читается как кинохроника.
- Речь бойцов сокращена до трёх реплик, чтобы слова уложились в 15 секунд движения.
- Без сети камера не запустится (библиотеки с CDN); ролик без камеры работает, пока он в кэше браузера.
