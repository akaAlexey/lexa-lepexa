# «Живое фото»: ручная проверка на телефоне

Автотесты проверяют логику: согласие, fallback, остановку камеры, субтитры, пометку ИИ, адреса файлов. На реальном телефоне остаётся то, что эмулятор не показывает: разрешение камеры в системе, звук после нажатия, индикатор камеры, свёртывание приложения. Этот список проходят перед показом на двух телефонах: Android (Chrome) и iPhone (Safari).

Ролики подготовлены командой заранее во внешних сервисах. Приложение их воспроизводит, а не создаёт. Так и говорим на показе.

## Перед началом

- [ ] **Адрес — только https.** Камера в браузере работает только на защищённом адресе. Сейчас `marshrutypobedy.ru` открывается лишь по `http://` (сертификат не выпущен), а `team-shpilit.github.io/lexa-lepexa` перенаправляет туда же. Для проверки AR — HTTPS-адрес: после «Enforce HTTPS» в настройках Pages или временный туннель `npm run tunnel` (ссылка `https://…lhr.life`).
- [ ] **QR.** QR на нынешних снимках ведёт на `akaalexey.github.io/…` — там 404 (`docs/audit/live-photo-scope.md`, LP-1). Пока снимки не перештампованы, страницу открываем по ссылке `https://<адрес>/live/soldier` и `…/live/reichstag`, а не по QR.
- [ ] Снимки распечатаны (кнопка «Скачать снимок с QR-кодом для печати») или открыты на втором экране в полный размер.
- [ ] Звук телефона включён, беззвучный режим выключен (iPhone: переключатель сбоку).
- [ ] Для Android: Chrome обновлён. Для iPhone: iOS 16 или новее, Safari.

## Сценарий

Для каждого телефона и каждого снимка (`soldier`, `reichstag`) ставим отметку в таблице результатов.

| #   | Действие                                                                      | Ожидаемо                                                                                                                                                        |
| --- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Открыть `/live/<id>`                                                          | Снимок, «Что прозвучит», пояснение «Ролик подготовлен командой заранее…», оговорка «Реконструкция с помощью ИИ…». Горизонтальной прокрутки нет                  |
| 2   | Не ставя галочку, нажать «Навести камеру» и «Смотреть без камеры»             | Обе кнопки неактивны, камера не спрашивается, ролик не играет                                                                                                   |
| 3   | Поставить галочку согласия → «Смотреть без камеры»                            | Плеер, ролик со звуком по нажатию «Play», плашка «Реконструкция с помощью ИИ» на ролике и внутри кадра, **русские субтитры включены** без действий пользователя |
| 4   | Развернуть плеер на весь экран                                                | Субтитры видны и в полноэкранном режиме (iPhone — системный плеер, «Субтитры» → «Русские субтитры», если не включились сами)                                    |
| 5   | Снять галочку согласия                                                        | Плеер закрывается, ролик останавливается, кнопки снова неактивны                                                                                                |
| 6   | Поставить галочку → «Навести камеру на снимок»                                | Система спрашивает доступ к камере (первый раз). Сверху — «Реконструкция с помощью ИИ» и крестик                                                                |
| 7   | Разрешить камеру, навести на снимок целиком                                   | За 1–5 с статус «Снимок ожил», ролик ложится ровно на рамку снимка, **звук есть**, внизу — текущая реплика субтитров                                            |
| 8   | Убрать снимок из кадра                                                        | Ролик на паузе, статус «Наведите камеру на снимок…». Вернуть снимок — ролик продолжает                                                                          |
| 9   | Нажать крестик                                                                | Экран камеры закрыт, **индикатор камеры гаснет** (Android — зелёная точка, iPhone — зелёная точка у часов), ролик на паузе                                      |
| 10  | Снова «Навести камеру» → свернуть браузер (домой) на 5 с → вернуться          | Индикатор камеры погас, пока браузер свёрнут. После возврата — «Камера выключена…», кнопка «Включить камеру снова» включает камеру заново                       |
| 11  | Запретить камеру (или запретить в настройках сайта) и нажать «Навести камеру» | «Доступ к камере запрещён. Разрешите камеру для этого сайта…» и «Смотреть без камеры», без зависания                                                            |
| 12  | Открыть по `http://` (без s) и нажать «Навести камеру»                        | «Камера работает только на защищённом адресе (https://)», переход к ролику работает                                                                             |
| 13  | Включить авиарежим на экране снимка, нажать «Навести камеру»                  | Не дольше 20 с — «Не удалось включить камеру…», камера погашена, «Смотреть без камеры» доступно (ролик — если он уже в кэше)                                    |
| 14  | Во время AR нажать «Смотреть без камеры»                                      | Камера гаснет, открывается плеер с субтитрами и плашкой ИИ                                                                                                      |
| 15  | Повернуть телефон в альбомную ориентацию в режиме камеры                      | Кнопки и статус видны, крестик доступен                                                                                                                         |

## Если что-то не так

| Симптом                        | Где смотреть                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Камера не спрашивается вообще  | Адрес не https (шаг 12); в Chrome — «Настройки сайта» → Камера                                                                        |
| Снимок не узнаётся             | Снимок целиком в кадре, без бликов; печать не меньше A5; цель `.mind` собрана из того же файла, что напечатан (`compile_targets.mjs`) |
| Нет звука в AR                 | Беззвучный режим на iPhone; звук «разблокируется» нажатием кнопки «Навести камеру» — нажимать её, а не открывать камеру другим путём  |
| «Включаем камеру…» дольше 20 с | Медленная сеть до jsDelivr (three.js и MindAR грузятся при открытии камеры)                                                           |
| Индикатор камеры не гаснет     | Ошибка: записать шаги, телефон и браузер — это дефект уборки (`ArView`, `platform/web/ar.ts`)                                         |
