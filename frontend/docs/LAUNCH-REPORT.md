# Готовность к запуску на marshrutypobedy.ru

Проверено 25.09.2026 на ветке `frontend-redesign` (новый дизайн поверх `frontend`), локальная сборка в демо-режиме.

## Вердикт

Приложение готово: 50 пользовательских сценариев на телефоне и ноутбуке проходят (100 из 100 прогонов после правок). **Выйти на домен сегодня нельзя** — четыре блокера, и все они вне кода.

## Блокеры

1. **Новый дизайн не на сайте.** Pages собирается только из `main`, а новый дизайн — в `frontend` и в патчах. Нужно слить `frontend-redesign` → `frontend` → `main`.
2. **HTTPS на домене.** `marshrutypobedy.ru` сейчас отдаёт сертификат не для этого домена. Нужно: Settings → Pages → Custom domain `marshrutypobedy.ru`, дождаться сертификата, Enforce HTTPS; переменные репозитория `SITE_BASE=/`, `SITE_URL=https://marshrutypobedy.ru`. Без HTTPS не работают камера (AR, «Живое фото»), геопозиция и уведомления.
3. **API.** `api.marshrutypobedy.ru` отвечает самоподписанным сертификатом, и браузер к нему не пойдёт. Нужен настоящий сертификат (Let's Encrypt), затем переменная `API_URL`. Пока её нет, сайт работает в демо-режиме: данные хранятся в браузере посетителя.
4. **152-ФЗ.** Заявка группы собирает телефон или почту. Согласие на обработку добавлено; нужна страница политики обработки персональных данных с оператором и контактом для отзыва согласия — это решение команды. С живым API — ещё уведомление Роскомнадзора об обработке ПДн.

Ещё до публикации:

- отозвать GitHub-токен и сменить пароль Deploy-F: они были в чате открытым текстом;
- перепечатать QR-коды: старые ведут на `akaalexey.github.io`, который больше не отвечает. Ссылки вида `/lexa-lepexa/…` на новом домене переадресуются сами.

## Сценарии

50 сценариев на двух экранах (телефон 360×780 и ноутбук 1366×768): семья 14, волонтёр 11, командир 7, краевед 3, общие 15. Скрипт: `tools/scenarios.cjs` (вне репозитория), скриншоты каждого шага сделаны.

Первый прогон нашёл девять проблем, восемь исправлены в коммите `5cf2341`, девятая — в ветке AR:

Нажатия: заявка командира — 3 от «Мероприятий», место гибели — 3 от карты, семья до первой точки — 2. Скорость локально: первый экран 0,2–0,3 с, карта 0,8 с на телефоне. JS — около 2,1 МБ без сжатия, больше всего весит MapLibre; Pages отдаёт gzip.

Замечено, но не правил (решить команде):

- ролик «Живого фото» не играет в Chromium без H.264 (Linux); на телефонах работает.

## После отчёта

- Офлайн (X5): сервис-воркер `public/sw.js` — после первого открытия тропа, карточки точек, карта и «Мероприятия» открываются и перезагружаются без сети; подложка карты сохраняется по мере просмотра (до 600 плиток).
- Заявка группы показывает все ошибки полей и согласия одним нажатием (раньше согласие прятало остальные); «Страница не найдена» ведёт на карту главной кнопкой.
- Прилипшая кнопка «Назад» больше не режет строки текста: вокруг неё кольцо «бумаги».
