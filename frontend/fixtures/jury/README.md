# Данные в формате жюри — ДЕМО

Настоящие файлы жюри (`mock_graves.csv`, `mock_battles.json`, `mock_teams.json`) в репозиторий пока не передали.
Эти файлы сгенерированы фронтендом **строго по схеме из кейса** и полностью вымышлены:
имена, номера частей у конкретных людей, координаты захоронений, суммы сборов. Тексты боёв помечены «Демо-текст».

Когда жюри выдаст свои файлы — положите их сюда с теми же именами и выполните `npm run fixtures`.
Скрипт проверит их схемой контракта и пересоберёт `src/api/fixtures/jury.generated.json`. Данные жюри синтетические, поэтому в интерфейсе они всегда помечены «демо».
