# Показ жюри: 3 минуты

Ссылка: **https://team-shpilit.github.io/lexa-lepexa/**. QR — `docs/qr-demo.png`.

Перед показом откройте две вкладки. В первой будет командир, во второй волонтёр. Скрытый пульт (`/lexa-lepexa/demo`, в меню его нет) подставляет геопозицию и сбрасывает данные, поэтому показ не зависит от GPS и сети.

## 0:00–0:20. Зачем

«Информация о войне в районах уходит вместе с краеведами. Мы собрали на одной карте семейные маршруты, помощь поисковикам и места гибели бойцов, которые ещё не подняты».

## 0:20–1:00. Семья: тропа (сценарий 1)

1. «Семья» → «Начать тропу».
2. Точка 1 «Рубеж десантников»: история, источник, задание для ребёнка. Ответьте неверно, потом верно.
3. Покажите карту: пунктир «след танка», 4 точки, около 3 км. Кнопка «Где я?».

Скажите: «Никаких очков за погибших — только штампы за пройденные точки».

## 1:00–1:40. Командир и волонтёр: «Последний бой» (сценарии 2 и 3)

1. Вкладка 2: «Волонтёр» → «Последний бой» → «Сообщать о находках рядом».
2. Вкладка 1: «Командир отряда» → «Последний бой» → «Отметить место гибели». Форма уже заполнена шаблоном экспедиции: 3 десантника 9-й бригады, октябрь 1941. «Опубликовать».
3. Вкладка 2: уведомление «В N км от вас обнаружено место гибели бойца».
4. Смените роль на «Краевед» → карточка места → «Подтвердить по архиву», «т. 5, с. 112». Статус «Подтверждено архивом», источник добавлен в карточку.

Скажите: «Точные координаты видят только отряды и краеведы. Это защита от чёрных копателей».

## 1:40–2:20. Штаб: люди и деньги (сценарий 2)

1. «Командир» → «Поисковикам» → «Набрать волонтёров» → «10» → «Опубликовать» — 3 нажатия.
2. «Волонтёр» → «Поисковикам» → «На карте»: где нужны люди, где деньги. Нажмите метку «Поднять бойца» → «Поддержать сбор» → тестовый платёж.
3. Оплата через ЮKassa (тестовый магазин, деньги не списываются): «Мероприятия» → фильтр «Сборы» →
   «Бензин на разведку у р. Оптуха» → «Пожертвовать» → сумма 500 ₽ → «Оплатить 500 ₽ через ЮKassa».
   Откроется страница ЮKassa с плашкой «Это тестовый платёж» → «Новая карта»:
   - номер **5555 5555 5555 4477**, срок — любой будущий (например, 12/30), CVC — любые 3 цифры;
   - «Заплатить» → ЮKassa вернёт на сайт, страница `/payment`: «Проверяем оплату…» →
     «Спасибо! Тестовый платёж прошёл», под ним «собрано … из …» — сумма выросла на 500 ₽.

   Покажите жюри плашку «Тестовый платёж — деньги не списываются» под кнопкой и выросшую сумму в ленте.
   Скажите: «Настоящий платёжный путь ЮKassa, но в тестовом магазине: реальные деньги не участвуют».
   Если ЮKassa не отвечает, сайт покажет «Не удалось начать оплату…» — переходите к следующему шагу.
   Без живого бэкенда (демо-данные) оплата имитируется сразу, без перехода на ЮKassa.

## 2:20–2:50. Память: хроника, памятники, «живое фото»

1. «Истории» → «Хроника и памятники»: бои 1941–1943 по годам и 84 настоящих памятника из OpenStreetMap. Найдите памятник морякам 116-й бригады Тихоокеанского флота — он упомянут в кейсе.
2. «Живое фото» → наведите телефон на распечатанный снимок с QR-кодом. Офицер говорит, губы совпадают с речью, стоит плашка «Реконструкция с помощью ИИ».

## 2:50–3:00. Итог

«8 задач кейса, 3 сценария покрыты автотестами на телефоне и ноутбуке, доступность WCAG AA. Дальше — Android из того же кода и генерация живого фото на сервере».

## Если что-то пошло не так

- Нет сети: карта тропы и карточки работают из кэша после первой загрузки.
- Нет камеры: в «Живом фото» есть «Смотреть без камеры».
- Нужно начать заново: пульт `/lexa-lepexa/demo` → «Сбросить демо-данные».
