# Аудит frontend UX и адаптивности — редизайн v3.1

25.09.2026. Проверена версия после восьми коммитов из `frontend-redesign-v3_1.patch.txt`, применённых к `frontend` в отдельной локальной ветке. Это аудит предложенной сборки, а не опубликованного сайта. Код приложения не менялся.

## Объём и достоверность

Изучены новый референс `frontend/docs/design/new_design/`, ADR 0012, снимки `frontend/docs/screenshots/{phone,laptop}`, CSS, роли, экраны, `Screen/Card/Button/BigButton/Field/Dialog`. Снимки в репозитории относятся к **старому** дизайну и не подтверждают внешний вид патча. `npm ci` и `npm run build:e2e` прошли. `npm run build` остановился на `src/api/mock/mockApi.test.ts:140:5` с `TS2722: Cannot invoke an object which is possibly 'undefined'`. Playwright не запустился: Chromium отсутствует, повторная загрузка завершилась ошибкой повреждённого ZIP. Фактические overflow, zoom и контраст пока **не измерены**.

## Изменения по сравнению с прошлой редакцией

Пять старых пунктов меню, прежняя шапка и прежняя компоновка карты заменены патчем, поэтому связанные с ними замечания сняты. Структура общих компонентов сохранена. Пожелание для веб-версии «Ваше местоположение» с вводом адреса остаётся отдельным открытым вопросом: `TrailScreen.tsx` по-прежнему предлагает «Где я?» через геопозицию; это не подтверждённое визуальное переполнение.
