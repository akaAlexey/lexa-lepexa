# Frontend UX, дизайн и адаптивность — повторный аудит

**Дата:** 25.09.2026. **Объект:** mock-приложение после применения всех восьми коммитов из `frontend-redesign-v3_1.patch.txt` к ветке `frontend` (локальная рабочая ветка `audit/redesign-review`, коммит `a7ac24b`). Код приложения в рамках аудита не изменён.

## Проверка и ограничения

Изучены референс `frontend/docs/design/new_design/`, ADR 0012, `Screen/Card/Button/BigButton/Field/Dialog`, токены, стили, маршруты, экраны семьи, волонтёра, командира и краеведа. Просмотрены сохранённые `frontend/docs/screenshots/phone/04-search.png` и `laptop/02-trail.png`: это **старый** дизайн, они не подтверждают вид версии v3.1.

Запущена mock-сборка `npm run build:e2e` через `vite preview`. Новый снимок сделан для карты, «Мероприятий» и «Историй» на 360×780, 683×384 и 1366×768. На шести адресах (`/map`, `/events`, `/archive`, `/other?section=account`, `/trail`, `/last-battle`) при каждом размере `documentElement.scrollWidth === clientWidth`: **горизонтальное переполнение не обнаружено**. 683×384 — эквивалент уменьшения CSS viewport ноутбука 1366×768 вдвое, но это **не проверка браузерного zoom 200 %**. В браузере для снимков отключено аппаратное и программное ускорение, поэтому карта отображается как fallback; оценка картографического слоя по ним невозможна.

`npm run typecheck` завершается ошибкой `src/api/mock/mockApi.test.ts:140:5 TS2722`. axe WCAG 2/2.1 AA на четырёх маршрутах при 360 и 683 px: на `/events`, `/archive`, `/other?section=account` нарушений в стандартной проверке нет; на `/map` найдено критическое `aria-valid-attr-value`. Проверка axe не охватывает все роли, состояния и ручную навигацию с клавиатуры.

## Снятые замечания предыдущей редакции

Прежние пять пунктов меню, старая шапка и старое размещение карты заменены патчем. Их нельзя переносить в аудит новой версии. В частности, на проверенных 360 px **нет** горизонтального переполнения. Сохранившиеся `Screen/Card/Button` и навигационную архитектуру переписывать для этих исправлений не требуется.

Отдельное требование ранее согласованной веб-версии — «Ваше местоположение» с вводом адреса вместо «Где я?» — остаётся открытым для `TrailScreen.tsx`; оно не является результатом измерения переполнения.

## Статус исправлений (25.09.2026)

Черновой PR #15 содержит редизайн v3.1 вместе с исправлениями P0-1…P0-5: обычная сборка восстановлена; поиск карты и состояние загрузки ленты проходят axe; главные действия зависят от роли и наличия заявки; демо-вход и вымышленные новости обозначены до действия; fallback карты читается под поиском. Исправлены видимый фокус, пустые состояния архива и ленты, общие loading/error/retry, подписи нижнего меню и пересчёт отступа карты при изменении высоты.

Проверено: `npm run build`, `npm run typecheck`, `npm run lint`, `npm run format:check`, 348/348 модульных тестов; axe на четырёх разделах при 360 и 683 CSS px — без нарушений. На шести маршрутах горизонтальной прокрутки нет при 360, 683 и 1366 px. Полный Playwright e2e не выполнен штатным раннером из-за недоступной загрузки Chromium. Реальный browser zoom 200 %, контраст на подложке с картой и сценарий ручного ввода адреса остаются на отдельную приёмку.
