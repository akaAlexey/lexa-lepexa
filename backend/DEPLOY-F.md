# Выкладка на Deploy-F

Бэкенд уже развёрнут: `https://a49734-6295.q.d-f.pw` (сайт на GitHub Pages ходит сюда).

## Тип проекта

Python-приложение, папка `backend/`. Команда запуска:

```text
python start.py
```

`start.py` сам применяет миграции (`alembic upgrade head`), заливает демо-данные в пустые таблицы и запускает Uvicorn
на порту из `PORT`.

## Переменные окружения

```text
DATABASE_URL=postgresql+asyncpg://USER:PASSWORD@HOST:PORT/DATABASE
CORS_ORIGINS=https://team-shpilit.github.io
SEED_DEMO=1
```

Пароль базы в git не кладём — только в настройках хостинга.

## Что произойдёт при обновлении до этой версии

1. Миграция `0003_contract_tables` добавит таблицы для тропы, штаба, сборов, выездов, коллективных заявок и архива.
   Существующие таблицы и данные не меняются.
2. `app.seed` добавит демо-данные, которых ещё нет (сейчас база на сервере пустая — появятся отряды, маршрут,
   заявки, выезды, истории и места). Повторные запуски ничего не дублируют.

## Проверка после выкладки

```text
GET /health                    → {"ok": true}
GET /api/v1/routes             → маршрут с 4 точками
```

Полная сверка с контрактом фронта (создаёт тестовые записи — лучше на копии базы):

```bash
cd frontend && npm run contract:check -- https://a49734-6295.q.d-f.pw/api/v1
```
